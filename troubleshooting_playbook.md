# Marketplace Troubleshooting Playbook

## 1. Define the Failure
Record the SKU, marketplace, upload method, timestamp, error text, and whether the issue affects one product or many.

## 2. Validate the Source
Check identifiers, product type, required attributes, variation values, images, and formatting.

## 3. Separate Data Errors from Platform Errors
Test a small clean sample and compare the result with marketplace documentation and account settings.

## 4. Correct the Root Cause
Fix the source data so the same issue is not reintroduced during the next bulk update.

## 5. Verify
Confirm live content, relationships, images, fulfillment data, and listing status after processing.

## Useful Diagnostic Fields
- Marketplace
- SKU
- Parent SKU
- Product type
- Error code
- Error message
- Source field
- Submitted value
- Corrected value
- Resolution status
